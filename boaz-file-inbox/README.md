# 📥 BOAZ 文件收件箱

**用途：** 你通过飞书发文件给我，我存到这里处理。

## 结构

| 目录 | 用途 |
|------|------|
| `products/` | 产品主图（前/侧/细节） |
| `gallery/` | 产品 SKU 色块图、模特图 |
| `sketch/` | 设计稿、logo、定制图案 |
| `misc/` | 其他 |

## 流程

1. 你发文件到飞书聊天（直接拖进来）
2. 我收到后存到对应目录
3. 处理完后更新产品数据/上传到网站
4. 处理完的文件会标记 ✅

> 命名规则：`<产品名>-<用途>-<序号>.jpg`
> 例：`280g-tee-front-01.jpg`, `xj78000-navy-01.jpg`
