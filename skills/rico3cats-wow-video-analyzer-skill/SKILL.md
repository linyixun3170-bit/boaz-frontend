# Rico3cats WOW 爆款拆解机

## 什么时候使用

当用户想做以下事情时使用本 Skill：

- 用 Rico3cats WOW 爆款拆解机分析一条短视频、小红书视频、账号作品或竞品爆款。
- 在本地部署、启动、排查这个视频爆款拆解工具。
- 根据工具导出的 TXT/JSON 分析报告，继续做选题复盘、脚本优化、封面标题优化或团队讨论。
- 想了解这个工具的 StepFun、FFmpeg、ASR、视觉模型、六维评分结构和隐私边界。

不要把本 Skill 当成通用“预测爆款”工具。没有真实视频、逐字稿、导出报告或用户提供的具体素材时，只能给拆解框架和准备清单，不能假装已经看过视频。

## 标准工作流

1. 先确认用户要做的是“运行工具分析视频”“解读已有报告”“改造工具源码”还是“把拆解结论转成脚本/选题”。
2. 如果要运行工具，按本地部署流程处理：
   - 确认 Node.js 18 或更高版本。
   - 准备 StepFun API Key。
   - 克隆或进入 `rico3cats/Rico3cats-wow-video-analyzer` 项目目录。
   - 运行 `npm install`，再运行 `npm start`。
   - 打开 `http://localhost:8765`。
3. 指导用户上传视频：
   - 支持 MP4、MOV、WebM、AVI 等常见视频格式。
   - 可以选择视频类型，也可以自动识别。
   - 可以填写额外分析要求，例如“重点看开头 3 秒”“重点看评论区引导”“按小红书教程类内容评估”。
4. 等工具完成四步处理：
   - FFmpeg 压缩视频到 720p。
   - FFmpeg 提取 MP3 音频。
   - StepFun ASR 生成中文逐字稿。
   - StepFun `step-3.7-flash` 结合视频和逐字稿输出 JSON 分析。
5. 解读结果时固定按六个维度输出：
   - 开头钩子
   - 脚本结构
   - 情绪曲线
   - 互动引导
   - 数据预测
   - 内容公式
6. 给修改建议时，必须落到可执行动作：
   - 开头怎么重拍或重剪。
   - 哪段口播该前置、删除或换说法。
   - 哪些画面、字幕、B-roll、评论区缺口可以补。
   - 标题和封面大字应该承接哪一个强钩子。

## 回答风格

- 先给结论，再给证据。
- 面向创作者和编导说人话，不写学术化评语。
- 区分“工具分析结果”和“我的进一步判断”。
- 如果用户没有提供真实视频或报告，不要编造分数、播放表现、完播率、评论率、收藏率。
- 如果报告里有明显模型幻觉或 JSON 字段异常，要指出可信度问题。
- 对小红书内容建议要具体到开头、字幕、封面、互动点、评论区缺口和复拍动作。

## 隐私和安全

- 这个项目默认面向本地使用，不建议裸露到公网。
- 上传视频会临时存到服务端 `uploads/`。
- 分析结果会临时存到服务端 `temp/`。
- 页面填写的 API Key 会发送到本地服务端用于本次分析。
- 只有用户勾选记住时，页面才会把 API Key 写入浏览器 `localStorage`。
- 团队部署前应补登录鉴权、上传大小限制、任务隔离、结果访问权限和服务端 Key 管理。
